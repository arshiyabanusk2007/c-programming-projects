# C Programming Projects

A collection of beginner-level C programs developed while learning programming fundamentals, problem-solving, and basic programming logic.

## Projects

### 1. ATM PIN Simulator

A simple program that verifies an entered ATM PIN using conditional statements.

**File:** `atm_pin_simulator.c`

### 2. Bill Splitter

A program that calculates the total bill and divides the amount among multiple people.

**File:** `bill_splitter.c`

### 3. Rainfall Tracker

A program that accepts daily rainfall values and calculates the total and average rainfall.

**File:** `rainfall_tracker.c`

## Skills Practiced

* C programming
* Variables and data types
* User input and output
* Conditional statements
* Loops
* Arithmetic operations
* Basic problem solving
